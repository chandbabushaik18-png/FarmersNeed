# FarmersNeed UI refresh

This version builds on the Phase 1 security/database ZIP, preserving its backend and existing HTML IDs and event handlers.

## Visual improvements
- New FarmersNeed brand bar and stronger, readable agricultural hero
- Four quick-action shortcuts to crop, weather, market, and drone services
- Unified forest-green/mint visual system, updated cards, softer corners and improved contrast
- Better Telugu font rendering using Noto Sans Telugu (Google Fonts, requires internet)
- Responsive 2-column shortcut layout on mobile
- Keyboard focus outlines and reduced-motion accessibility support
- Consistent footer and clearer service navigation

## Notes
- This is a UI refresh, not a replacement of the existing workflows.
- The Phase 1 login/profile and booking limitations documented in UPGRADE_PLAN.md still apply.
- Remote photos and fonts require internet; local fallbacks remain for fonts.
- Review with Telugu-speaking users, and run browser tests before production deployment.
